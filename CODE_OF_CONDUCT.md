# Code of Conduct

This project follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standard

We want a friendly, harassment-free space for everyone, regardless of age, background, identity, experience level, or nationality.

Expected behaviour:

- Be respectful and patient; assume good intent.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the project and the people using it.

Unacceptable behaviour:

- Harassment, insults, personal attacks, or discriminatory language or jokes.
- Publishing someone's private information without permission.
- Trolling, or sustained disruption of discussions.

## Enforcement

Maintainers may edit or remove comments, commits, issues, and other contributions that don't follow this Code of Conduct,
and may temporarily or permanently ban contributors for behaviour they judge inappropriate.

To report a problem, contact the maintainer through their GitHub profile or open a private security advisory on the repository
(it reaches the maintainers without being public). Reports are handled confidentially.

This applies in all project spaces: issues, pull requests, discussions, and any place where someone represents the project.
